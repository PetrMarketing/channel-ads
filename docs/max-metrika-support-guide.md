# MAX Маркетинг: подписки и цели Яндекс Метрики

## Что показывает экран «Трекинг-ссылки»

Для каждой ссылки факты разделены на три этапа:

1. **Подписка подтверждена** — MAX прислал webhook о вступлении пользователя.
2. **Привязана к рекламному визиту** — подписка связана с визитом того же MAX-пользователя, чья личность была проверена подписанными данными MAX. Подписки без такого визита показываются отдельно и не приписываются ссылке.
3. **Цель Метрики** — показано состояние браузерной доставки. «Передано браузером» означает только успешное завершение callback `reachGoal`, но не подтверждение появления цели в отчёте Метрики.

## Настройка ссылки

1. Откройте «Трекинг-ссылки» и нажмите кнопку 📊 у нужной ссылки.
2. Укажите цифровой номер счётчика.
3. В кабинете Метрики откройте этот счётчик → «Цели» → «Добавить цель».
4. Выберите тип «Целевое событие», условие «совпадает» и задайте тот же идентификатор, например `subscribe_channel`.
5. Нажмите «Проверить настройку без отправки цели». Проверка валидирует формат и показывает шаги, но не вызывает `reachGoal`, не создаёт подписку и не загрязняет рабочую кампанию.
6. Сохраните настройку.

API/OAuth-токен Метрики для этого режима не требуется. Существование цели в конкретном счётчике без доступа к кабинету проверить нельзя.

## Почему подписка есть, а цели нет

- **Подтверждена без рекламной привязки** — не найден проверенный рекламный визит этого MAX-пользователя. Случайной ссылке такая подписка не назначается.
- **Метрика не настроена / ошибка настройки** — отсутствует или неверен номер счётчика либо идентификатор цели.
- **Ожидает отправки** — подписка подтверждена, но браузерная попытка ещё не завершилась.
- **Подтверждена, но не доставлена** — настройка отсутствовала либо живая страница не забрала событие в течение десяти минут. Событие сохранено, но сервер не подменяет его фиктивным визитом.
- **Проблема доставки** — попытки закончились ошибкой или браузер был закрыт до подтверждения callback.
- **Передано браузером** — браузерный транспорт завершился, однако это не доказательство учёта цели. Итог проверяется в кабинете Метрики с учётом задержки обработки.

## Ограничение режима без API

`reachGoal` работает только пока страница пользователя открыта. Если подтверждение подписки пришло после закрытия страницы, сервис сохраняет подтверждённую конверсию, но автоматически дослать её сервером без Measurement Protocol/API-токена не может. Нельзя заменять такую конверсию кликом или фиктивным визитом.
