# Экономика полной генерации ИИ Агента

Расчёт на один полный проект (верхняя граница включённого объёма):

- 2–3 млн входных текстовых токенов;
- 0,6–0,9 млн выходных текстовых токенов;
- 80–150 поисковых/страничных запросов;
- 200–260 изображений 1K;
- 30% резерв на повторы, правки и неуспешные генерации.

## Себестоимость API

| Компонент | Рабочая модель | Оценка |
|---|---|---:|
| Извлечение и классификация | GPT-5.4 nano | $0.5–1.5 |
| Стратегия и финальные тексты | GPT-5.4 mini | $4–8 |
| Поиск и загрузка источников | web/search | $1–3 |
| 200–260 изображений 1K | Gemini 3.1 Flash Image | $13.4–17.4 |
| Повторы и технический резерв | 30% | $5.7–9.0 |
| **Итого переменная себестоимость** | | **$25–39** |

Сервер, хранение файлов, эквайринг и поддержка в эту сумму не входят.
Для финансового планирования использовать безопасный лимит **$40 на проект**.

## Розничная цена

3990 ИИт при текущей минимальной цене 2.55 ₽/ИИт = 10 174.50 ₽.

При курсе 80–100 ₽/$ выручка составляет примерно $102–127, а валовая маржа
после API — ориентировочно 61–80%. После эквайринга, инфраструктуры и поддержки
целевой фактический диапазон маржи: 55–70%.

## Ограничения включённого объёма

Чтобы себестоимость оставалась прогнозируемой, пакет должен включать не более:

- 20 анализируемых конкурентов;
- 10 лид-магнитов;
- 5 воронок;
- 2 чат-ботов на готовых конструкторах;
- 2 мини-приложений на шаблонах;
- 156 постов, 104 вертикальных и 52 длинных сценариев;
- 260 сгенерированных изображений;
- 2 раундов крупных правок.

Уникальная разработка вне шаблонов и дополнительные изображения оцениваются отдельно.
