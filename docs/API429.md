# AI provider routing

API429 is primary for all backend text, tool-use and image Chat Completions.
Create backend-python/.env.api429 from .env.api429.example and set API429_API_KEY
on each server before deploying. This file is excluded from git and Docker images.
Docker Compose supplies it at runtime. The existing OpenRouter key and proxy
remain in backend-python/.env as the backup credentials.

Fallback occurs on exhausted API429 balance (HTTP 402), network/body-read timeout,
HTTP 408/429/5xx, or malformed successful responses.
HTTP 400/401/403/404 do not trigger OpenRouter.
No circuit breaker: each new request tries API429 first, so recovery is automatic.
Timeouts may represent an already billed request; avoid repeated manual retries.

API429 model mappings (verified against this key's /v1/models):
- GPT-5.4 Nano and GPT-4o Mini -> GPT-5.4 Mini
- GPT-4o -> GPT-5.4
- Claude Sonnet 4 -> Claude Sonnet 4.6
- Gemini Flash Lite Image -> Gemini 3.1 Flash Image
- Other models retain their ID without the OpenRouter vendor prefix.

OpenRouter fallback retains the original model ID and uses its own key/proxy.
API429 requests go directly to https://gateway.api429.com/v1/chat/completions.
Reference: https://client.api429.com/documentation
